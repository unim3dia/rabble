# Rabble

The live server for [Rabble](https://unim3dia.github.io/rabble/): add your own
photo and become a little clay figure in the pile (Muse Image + SAM 3.1), and
talk with the pile (Muse Spark).

The code lives on GitHub: https://github.com/unim3dia/rabble. This Space is
built from it by `space/deploy.sh`. The Meta key is a Space secret.
